# Ⲕⲁⲧⲁⲙⲉⲣⲟⲥ - katameros-web-app

Front-end for the daily readings in the Coptic Orthodox Church. Supports multiple languages.

Website https://katameros.app/en/

Android https://play.google.com/store/apps/details?id=com.dcoanbamarc.katamerosmobile

iOS https://apps.apple.com/app/id6475370514

See Readme at [katameros-api](https://github.com/pierresaid/katameros-api/tree/master#readme)

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
